# Code of Conduct

We want this project to be a welcoming, technically rigorous, and respectful open-source community.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and implementations, not people.
- Assume good intent while remaining precise about technical issues.
- Share reproducible evidence when reporting problems.
- Treat security reports and sensitive information responsibly.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disclosure of private information, and other abusive conduct are not acceptable.

## Enforcement

Project maintainers may remove or edit contributions that violate this code and may restrict participation when necessary to protect the community.

For sensitive concerns, contact the project maintainer privately through the contact method listed on the project website.
