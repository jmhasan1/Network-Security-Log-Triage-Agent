# Evaluation

This directory contains all experiment reports, benchmark results, model comparisons, and evaluation artifacts for the Network Security Log Triage Agent.

Unlike the `docs/` directory, which explains the system architecture and implementation, this directory records empirical results used to compare models and guide development.

Contents include:

- Baseline reports
- Experiment logs
- Version benchmarks
- Evaluation figures
- MLflow summaries

As the project evolves, this directory will also include Retrieval-Augmented Generation (RAG) and Agent evaluation reports.
